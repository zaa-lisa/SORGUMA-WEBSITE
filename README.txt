SORGUMA Website - Editable VS Code Project

Cara membuka:
1. Extract ZIP ke satu folder.
2. Buka folder tersebut di VS Code (File > Open Folder).
3. Klik dua kali index.html atau buka dengan Chrome.

Penting: jangan pisahkan index.html dari folder assets. Foto produk berada di assets/sorguma.jpg.
Data checkout demo disimpan di browser yang digunakan (localStorage), bukan ke server online.
